Catalogue

Intro

A program in satis is a list of equations that ultimately define out. As an example: 
				out = "hello world"
This program displays the text "hello world" in the output pane. The equations get updated automatically. To display a simple timer, we can write the program 
				out = floor(runtime)
This program will display an increasing timer on the right. We can also draw shapes using the function "draw". This function takes one or more shapes and outputs them in a freshly constructed canvas. 
				out = draw sq
				sq = square(0,0,10)
Note that the variable sq is used before it is defined. The programs are all declarative, which means that the order of the equations doesn't matter.

Coordinates

When using the draw function, the screenspace is represented in coordinates. (0, 0) is down left, (0,100) is up left, en (screen.width, 100) is up right. The height is always 100 but the width can differ based on screen size.

If-statements

We can use regular if-statements when desired by using them in the following way. 
			if runtime < 5 then
				out = "soon"
			else
				out = "later"
			end
This program will first display "soon", and after five seconds "later".

Assignments

We can define variables that change when something happens using the following assignment syntax. 
			out := 0
			if mouse.click.begin then
				out := out + 1
			end
This program will output the number of clicks in the output pane. Note that the first assignment is outside any if-block and will be executed at the start of the program.

Controls

The forward and backward buttons are meant to navigate the various examples. When editing the code it will be stored in local storage so it survives page refreshes. The pause button pauses your program, the play/stop button compiles or stops your program, and the diagonal arrow towards a corner makes the app fullscreen. Press escape to leave fullscreen mode. To quickly apply changes, press Shift-Enter to recompile. For vim fanatics: press Shift-Escape once to enable vim support.
